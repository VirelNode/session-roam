**Health check with retry (per D-13):**
```bash
wait_for_syncthing() {
    local api_key="$1"
    local max_attempts=20
    local attempt=0
    info "Waiting for Syncthing API..."
    while [[ $attempt -lt $max_attempts ]]; do
        if curl -sf -H "X-API-Key: ${api_key}" \
            "http://127.0.0.1:8384/rest/system/status" >/dev/null 2>&1; then
            ok "Syncthing API is responding"
            return 0
        fi
        attempt=$((attempt + 1))
        sleep 0.5
    done
    die "Syncthing API did not respond within 10 seconds"
}
```

get_device_id() {
    syncthing cli show system 2>/dev/null \

Define a function to add a single peer device (both globally and to the folder):
```bash
add_peer_device() {
    local device_id="$1"
    local device_name="${2:-peer}"

    # Add device globally (idempotent check)
    if syncthing cli config devices list 2>/dev/null | grep -q "^${device_id}$"; then
        ok "Device ${device_id:0:7}... already known"
    else
        syncthing cli config devices add \
            --device-id "$device_id" \
            --name "$device_name" \
            --auto-accept-folders
        ok "Device ${device_id:0:7}... added"
    fi

    # Share claude-sessions folder with this device
    syncthing cli config folders claude-sessions devices add \
        --device-id "$device_id" 2>/dev/null || true
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> shell commands | Device IDs from CLI args or interactive prompt are passed to syncthing cli |
| Script -> Syncthing REST API | API key extracted from config.xml, used in curl headers |
| Script -> package manager | apt-get/brew install commands (require network access) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Device ID input | mitigate | Syncthing CLI validates device IDs internally and rejects malformed ones (per RESEARCH.md). All bash variables are double-quoted to prevent word splitting/globbing. No eval or unquoted expansion of user input. |
| T-01-02 | Information Disclosure | API key in process list | mitigate | API key passed via curl -H header (not URL parameter). config.xml has 0600 permissions by default. API key variable is local-scoped in functions. |
| T-01-03 | Elevation of Privilege | Running as root | mitigate | Script checks `$EUID -eq 0` at startup and exits immediately if root (per D-08). Never calls sudo except for apt-get install. |
| T-01-04 | Tampering | config.xml symlink | accept | mkdir -p for .stfolder does not follow symlinks for the final path component. config.xml is owned by the user and in a user-owned directory. Low risk for single-user setup. |
| T-01-05 | Denial of Service | API health check timeout | mitigate | Health check has a 10-second timeout (20 attempts at 0.5s). Script dies with clear error message if API never responds, rather than hanging indefinitely. |
</threat_model>
